# Автообновление через GitHub

Оба приложения умеют проверять `latest.json` и предлагать обновление.
Android сам скачивает APK и открывает установщик; UWP скачивает APPX и
открывает системный установщик (тихо установиться он не может).

## 1. Создать публичный репозиторий

Например `crimtube-releases`. В нём будут только релизы и `latest.json`,
исходники можно не выкладывать.

## 2. Добавить latest.json

Файл `latest.json` в корне репозитория (ветка `main`):

```json
{
  "android": {
    "versionCode": 31,
    "url": "https://github.com/USER/REPO/releases/download/v0.3.1/CrimTube-0.3.1.apk",
    "changelog": "Автообновление, mux-сервер, выбор качества."
  },
  "uwp": {
    "version": "0.4.7.0",
    "url": "https://github.com/USER/REPO/releases/download/v0.4.7/CrimTube.UWP_0.4.7.0_ARM.appx",
    "changelog": "Автообновление и проверка обновлений в настройках."
  }
}
```

- Android сравнивает **versionCode** (целое).
- UWP сравнивает **version** (строка вида `0.4.7.0`).
- `url` — прямая ссылка на файл релиза.

## 3. Создать релиз и загрузить файлы

1. GitHub → Releases → **Draft a new release**.
2. Tag: `v0.3.1` (для Android) и/или `v0.4.7`.
3. Прикрепить:
   - `CrimTube-0.3.1.apk` — подписан тем же ключом, что установлен на планшете;
   - `CrimTube.UWP_0.4.7.0_ARM.appx` — подписан тем же сертификатом.
4. Publish release.

Ссылки в `latest.json` должны точно совпадать с именами файлов.

## 4. Прописать URL в приложениях

- **Android**: меню → «Обновления» → вставить URL `latest.json` → «Проверить».
- **UWP**: Настройки → «Обновления (URL latest.json)» → вставить URL → «Проверить обновления».

URL варианта raw:

```
https://raw.githubusercontent.com/USER/REPO/main/latest.json
```

Если raw-ссылка кэшируется, используйте jsDelivr:

```
https://cdn.jsdelivr.net/gh/USER/REPO@main/latest.json
```

## 5. Как это работает

### Android

1. При запуске (не чаще раза в сутки) или по кнопке читает `latest.json`.
2. Если `versionCode` больше установленного — показывает changelog.
3. По «Скачать» качает APK во внутреннюю папку.
4. Открывает установщик через content:// (Android 7+).
5. Пользователь подтверждает установку. На Android 8+ нужно разрешить
   «Установка неизвестных приложений» для CrimTube.

### UWP

1. Проверка при запуске/по кнопке.
2. Если версия новее — показывает changelog.
3. Скачивает APPX в `LocalFolder`.
4. Открывает установщик через `Launcher.LaunchFileAsync`; пользователь
   подтверждает установку.

## 6. Важно

- Подпись APK/APPX **не меняется** — иначе обновление не встанет поверх.
- Android `versionCode` всегда увеличивать; UWP `Version` в манифесте тоже.
- Репозиторий должен быть **публичным**, иначе raw/релизы недоступны без токена.
- Не кладите в релиз keystore/пароли.
- GitHub API не используется, поэтому лимиты запросов не мешают.
